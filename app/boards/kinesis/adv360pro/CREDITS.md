# Credits

The Advantage 360 Pro features in this tree are a forward port, onto ZMK `main`
(Zephyr 4.1), of the Kinesis firmware at
[ReFil/zmk `adv360-z3.5-2`](https://github.com/ReFil/zmk/tree/adv360-z3.5-2)
(`d93499bb`, 36 commits over ZMK `3377ed02`). The design and most of the code
are the work of its authors: **ReFil**, **Keeley Hoek**, **Willow Herring**,
**Frank Blanning** and **David Dreschner**. The split lighting sync was re-hosted on ZMK's newer
split transport, so it was largely rewritten; everything else follows their
code closely.

Commits below are on `ReFil/zmk`. The `[Cn]` tags match the feature commits in
this tree.
